# Implementation profiles

These MIN and MAX profiles are active design examples retained from the first experiment. They demonstrate two proportional ways to apply the functional profile:

- `min/` — one operator applies VSM lenses selectively;
- `max/` — responsibilities are separated when concurrency, evidence independence, or context isolation has demonstrated value.

They are not conformance levels and do not imply that a viable harness needs six agents. `MODULAR` means using selected MAX prompt modules within one operator rather than introducing additional actors.

The YAML, state, issue, and prompt files under `max/` are local examples, not VSM manifests or ecosystem standards. Implementations may use entirely different representations.

Prefer MIN until evidence shows that separation regulates more variety than it creates.
